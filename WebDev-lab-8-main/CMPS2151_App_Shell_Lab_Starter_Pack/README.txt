CMPS2151 — App Shell Transfer Lab Starter Pack

Choose ONE application folder:
- eventflow
- helpdesk
- labcare
- losttrack
- stockroom

Each folder contains:
- index.html        Minimal HTML starter
- css/reset.css     The class reset.css (do not rewrite it)
- css/token.css     The colour scheme for that app
- css/main.css      Your stylesheet — build the shell here
- mockup.png        Your visual reference
- svg-tags.html     Inline SVG snippets you may copy into index.html

IMPORTANT LAB BOUNDARY
Build ONLY the App Shell / App Chrome:
- brand block
- navigation rail
- active Dashboard link
- pinned Log out action
- topbar
- initials avatar
- user name and chevron

The <main> element must remain EMPTY for this lab.
Do not build the dashboard cards, filters, search box, lists/tables,
status pills, pagination, or any other dashboard content.

No JavaScript is required or permitted for the app shell.

SVGs
Open svg-tags.html in the browser. Find the section for your chosen app,
copy the SVG tag you need, and paste it directly into index.html.

CSS load order
reset.css -> token.css -> main.css
